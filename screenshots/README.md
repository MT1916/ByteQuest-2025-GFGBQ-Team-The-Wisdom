# Screenshots Directory

This directory contains screenshots of the ZakaatChain application for the README.

## Required Screenshots

Please add the following screenshots to this directory:

1. **landing-page.png** - Homepage/landing page of the application
2. **donor-dashboard.png** - Donor dashboard showing donation tracking
3. **ngo-dashboard.png** - NGO dashboard with campaign management
4. **validator-dashboard.png** - Validator dashboard for expense review
5. **campaign-details.png** - Detailed view of a campaign
6. **wallet-connection.png** - MetaMask wallet connection flow

## How to Add Screenshots

1. Take screenshots of your running application
2. Save them with the exact filenames listed above
3. Place them in this `screenshots/` directory
4. The README will automatically display them

## Screenshot Guidelines

- **Resolution**: Minimum 1920x1080 for desktop views
- **Format**: PNG (preferred) or JPG
- **Content**: Show actual application features, not placeholder content
- **Quality**: Clear, high-quality images that showcase functionality
- **Privacy**: Don't include sensitive information (private keys, real addresses)

## Alternative

If you don't have screenshots yet, you can:
- Use placeholder images temporarily
- Update the README to remove screenshot references
- Add screenshots before final submission
